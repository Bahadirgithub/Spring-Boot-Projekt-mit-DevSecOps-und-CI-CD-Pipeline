# Spring-Boot-Projekt-mit-DevSecOps-und-CI-CD-Pipeline
Spring-Boot-Plattform zur Unterstützung von Gründern beim Start-up-Aufbau. Entwickelt nach Scrum mit Anforderungsartefakten &amp; Vaadin. Automatisiert &amp; abgesichert über eine CI/CD &amp; DevSecOps-Pipeline mit Maven, Jenkins und SonarQube.



Project Overview:
Development of a dedicated platform designed to effectively support founders and entrepreneurs in building and scaling their start-ups by streamlining management, resources, and collaboration.

Methodology & Project Management:
The project followed agile principles using Scrum, incorporating comprehensive requirement artifacts (such as user stories, use cases, and backlog management) to ensure structured development from conception to execution.

Tech Stack & DevSecOps Pipeline:
Backend & Core: Java, Spring Boot, Maven
Frontend: Vaadin
CI/CD Automation: Jenkins for continuous integration and automated pipelines.
DevSecOps & Code Quality: SonarQube for automated static code analysis, vulnerability detection, and security gating.
((This project is developed as a group project.))
