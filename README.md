# Spring-Boot-Projekt-mit-DevSecOps-und-CI-CD-Pipeline
Spring-Boot-Plattform zur Unterstützung von Gründern beim Start-up-Aufbau. Entwickelt nach Scrum mit Anforderungsartefakten &amp; Vaadin. Automatisiert &amp; abgesichert über eine CI/CD &amp; DevSecOps-Pipeline mit Maven, Jenkins und SonarQube.
